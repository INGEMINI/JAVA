Important Methods from Throwable Class

## Method Name : Description

getMessage() : Returns a detailed description of the exception.
printStackTrace() : Prints the complete stack trace – useful for debugging.
toString() : Returns the exception class name along with the message.
getCause() : Returns the cause of the exception, if available.
getLocalizedMessage() : Returns the localized version of the exception message.// Message in local language (rarely used).
fillInStackTrace() : Updates the stack trace (advanced use).
